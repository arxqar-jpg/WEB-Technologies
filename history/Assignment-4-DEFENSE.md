# Assignment 4 - қорғауға дайындық

Тапсырмалардың кодтары `js/script.js` ішінде. Бастапқы жобадағы жауапкершілік бөлінісі сақталған: Darkhan Saduakasov - форма тексеруі, уақыт, quiz; Kassymkhan - FAQ, popup, фон. Екеуі де барлық кодты түсіндіріп бере алуы керек.

1. **Form validation.** Submit оқиғасында `preventDefault()` бетті қайта жүктетпейді. Барлық өріс жеке тексеріледі. Бос ат, қате email, 8 таңбадан қысқа пароль, сәйкес келмейтін растау және келісімсіз жіберу қате көрсетеді. `input` оқиғасы өзгерісті бірден қайта тексереді.
2. **Парольдегі пробел.** `beforeinput`, `paste`, `drop` оқиғалары бос орын мен көрінбейтін таңбаларды кіргізбейді. Submit кезінде бастапқы мән қайта тексеріледі. Парольді `trim()` арқылы өзгертіп жібермейміз. Жоба парольді сақтамайды.
3. **Email.** Regex пен домен ережелері форматты тексереді. Мысал, анық жалған, белгілі уақытша адрес пен кейбір домен қателері қабылданбайды. Кез келген адрес шынымен бар екенін frontend біле алмайды: нақты тіркелуде email-ге код/сілтеме жіберетін сервер қажет.
4. **FAQ accordion.** Барлық жауап басында жабық. Button click `active` класын, `aria-expanded`, `aria-hidden` және `maxHeight` мәнін өзгертеді. `scrollHeight` жауаптың нақты биіктігін береді, CSS transition оны жұмсақ ашады. Қайта басса жабылады.
5. **Popup.** Батырма overlay-ді көрсетеді. Жабу батырмасы, фонға басу және Escape жабады. `inert` фондағы элементтерге өтуді тоқтатады. Tab popup ішінде қалады, жабылғанда фокус бастапқы батырмаға қайтады.
6. **Фон.** Palette - бірнеше түсі бар массив. `(index + 1) % palette.length` соңғы түстен кейін біріншісіне қайтарады. JavaScript `document.body.style.backgroundColor` мәнін өзгертеді. localStorage тек тақырып индексін сақтайды; ол істемесе де қалған функциялар жұмыс істейді.
7. **Уақыт.** `new Date()` ағымдағы уақытты алады. `Intl.DateTimeFormat` оны оқылатын мәтінге айналдырады. `setInterval(updateTime, 1000)` әр секунд жаңартады. Уақыт браузердің жергілікті timezone-ымен көрсетіледі.
8. **Quiz.** Таңдалған жауаптар дұрыс мәндермен дәл салыстырылады. Барлық сұраққа жауап болмаса ескерту шығады. Пайыз: `Math.round(score / total * 100)`. Жауап өзгерсе бұрынғы нәтиже тазарады.

Демонстрация реті: сайтты ашу -> сағаттың жаңаруын көрсету -> Change Theme -> Sign Up-та бос форманы жіберу -> қате email/пароль -> дұрыс мәндер -> Newsletter popup-ты үш тәсілмен жабу -> FAQ ашу/жабу -> quiz нәтижесі -> телефон өлшемін көрсету.

Тапсырар алдында: есепке топты және нақты жарияланған URL-ды толтырыңыз. PDF-тегі жалпы бағаның 40%-ы қорғауға тиесілі, сондықтан әр функцияның қалай жұмыс істейтінін өз сөзіңізбен түсіндіріп дайындалыңыз.
