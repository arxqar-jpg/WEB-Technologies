# Forest нұсқасындағы жаңартулар

Таңдалған Forest интерфейсі негізгі жобаға қолданылды.

## Көрініс пен қаріптер

- Тақырыптар: Sora. Негізгі мәтін мен батырмалар: Figtree. Қаріптер жобаның ішінде, интернетсіз жүктеледі.
- Сол жақта тұрақты мәзір; жоғарғы жолақта уақыт, Sign up және тема таңдағышы бар.
- Forest / Midnight / Cobalt толық түстері ауысады. Таңдау басқа бетке өткенде сақталады.
- Overview бетінде іздеу, autocomplete, категория сүзгісі және квиздер тізімі бар.
- Мобильді мәзір Bootstrap hamburger арқылы ашылады.

## Жаңартылған сұрақтар

Әр тақырыпта 3 сұрақ, барлығы 9 сұрақ сақталды. Барлығы қысқа, статикалық кодты түсінуге бағытталған:

- Java: score += 3 нәтижесі; for циклі; объект құру.
- Python: list индексі; функциядағы шекаралық шарт; циклдегі қосынды.
- HTML/CSS: form submit; id селекторы; media query ішіндегі бір бағанды grid.

Браузер кодты орындамайды: оқушы кодты оқып, radio жауабын таңдайды. Бұрынғы JS бағалау тәсілі сақталды. Java және Python мысалдарының нәтижелері бөлек тексерілді.

## Бұрынғы талаптар қайда

- Study Lab: жоспар, Next/Back callback, Reset, дыбыс, галерея және Copy plan.
- Registration / Newsletter / Contacts: validation, spinner, disabled Submit және toast.
- Барлық бет: jQuery 4, ready console message, scroll progress, lazy loading және команда аты жазылған footer.
- Overview -> Resources & FAQ: CSS-only 1/2/3 карточкалар, Bootstrap екі/үш бағандары, image cards, 9 суретті carousel және FAQ accordion. Бөлімді ашып қарауға болады.
